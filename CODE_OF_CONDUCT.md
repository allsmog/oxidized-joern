# Code of conduct

We want project spaces to be useful, respectful, and safe for participants of
all backgrounds and experience levels.

Be constructive, assume good faith, criticize ideas rather than people, and
respect boundaries. Harassment, threats, discriminatory language, deliberate
disruption, and publishing another person's private information are not
acceptable.

Maintainers may edit or remove contributions and restrict participation when
needed to protect the project or its community. When possible, enforcement
will be proportionate and will explain the behavior that must change.

Report abusive GitHub content with GitHub's private reporting tools. For a
sensitive safety or security concern involving this project, use the private
reporting link in [`SECURITY.md`](SECURITY.md). Do not post private evidence in
a public issue.
