# Security policy

## Supported versions

Security fixes are made on the default branch and included in the next tagged
release. Only the latest tagged release is supported.

## Report a vulnerability

Please use
[GitHub private vulnerability reporting](https://github.com/allsmog/oxidized-joern/security/advisories/new).
Do not open a public issue for a suspected vulnerability and do not include
secrets or exploit details in ordinary pull requests.

Include the affected revision, platform, reproduction steps, impact, and any
suggested mitigation. Maintainers aim to acknowledge a complete report within
five business days. Disclosure timing will be coordinated with the reporter
after the impact and fix are understood.

## Scope

Reports about this fork's source, release archives, installer, container, CI,
or Rust-native engine are in scope. Issues that reproduce only in upstream
Joern should also be reported to the upstream project's security contact.
